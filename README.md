# 🎮 Secret CFW - نظام التفعيل الاحترافي

نظام متكامل لإدارة تفعيل اللاعبين لسيرفر FiveM، يتضمن موقع ويب احترافي وبوت Discord متكامل.

<div dir="rtl">

## 📋 المميزات الرئيسية

### 🌐 الموقع الإلكتروني
- تصميم عصري متجاوب مع دعم كامل للغة العربية (RTL)
- هوية بصرية متحركة بألوان الأزرق والرصاصي
- تسجيل دخول عبر Discord OAuth
- نظام صلاحيات متقدم مرتبط برتب Discord
- لوحة تحكم للأعضاء ولوحة إدارية كاملة

### 🤖 بوت Discord
- داشبورد تفعيل ثابت في قناة مخصصة
- إشعارات تلقائية للإدارة
- أزرار تفاعلية للقبول/الرفض/طلب التعديل
- مزامنة الرتب تلقائياً
- إرسال إشعارات للأعضاء عند تحديث حالتهم

### 👥 نظام الصلاحيات
- **إدارة عليا (SUPER_ADMIN)**: صلاحيات كاملة
- **إدارة التفعيل (ACTIVATION_ADMIN)**: مراجعة الطلبات واتخاذ القرارات
- **إدارة عامة (GENERAL_ADMIN)**: إدارة بنك الأسئلة والإعدادات

### 📝 نظام التفعيل
- نموذج تقديم شامل (الاسم، العمر، اسم الشخصية، القصة)
- أسئلة اختبار عشوائية من بنك الأسئلة
- أربع حالات للطلب: انتظار، مراجعة، مقبول، مرفوض
- إمكانية إعادة التقديم بعد الرفض
- نظام أولوية للأعضاء المميزين

## 🚀 التثبيت والإعداد

### المتطلبات
- Node.js 18+
- PostgreSQL
- حساب Discord Developer

### الخطوات

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd secret-cfw
npm install
```

2. **إعداد قاعدة البيانات**
```bash
# إنشاء قاعدة بيانات PostgreSQL
# ثم تحديث DATABASE_URL في ملف .env

# تطبيق المخطط
npm run db:push

# توليد عميل Prisma
npm run db:generate
```

3. **إعداد متغيرات البيئة**
```bash
cp .env.example .env
# ثم تعديل القيم في ملف .env
```

4. **تشغيل التطوير**
```bash
npm run dev
```

5. **البناء والتشغيل**
```bash
npm run build
npm run start
```

## ⚙️ متغيرات البيئة

| المتغير | الوصف |
|---------|-------|
| `DATABASE_URL` | رابط اتصال PostgreSQL |
| `NEXTAUTH_URL` | رابط الموقع |
| `NEXTAUTH_SECRET` | مفتاح سري (32 حرف+) |
| `DISCORD_CLIENT_ID` | معرف تطبيق Discord |
| `DISCORD_CLIENT_SECRET` | سر تطبيق Discord |
| `DISCORD_BOT_TOKEN` | توكن البوت |
| `DISCORD_GUILD_ID` | معرف السيرفر |
| `SUPER_ADMIN_ROLE_ID` | معرف رتبة الإدارة العليا |
| `ACTIVATION_ADMIN_ROLE_ID` | معرف رتبة إدارة التفعيل |
| `GENERAL_ADMIN_ROLE_ID` | معرف رتبة الإدارة العامة |
| `PRIORITY_ROLE_ID` | معرف رتبة الأولوية |
| `ACTIVATED_ROLE_ID` | معرف رتبة التفعيل |
| `ADMIN_NOTIFICATIONS_CHANNEL_ID` | قناة إشعارات الإدارة |
| `DASHBOARD_CHANNEL_ID` | قناة الداشبورد |
| `ACTIVATION_LOG_CHANNEL_ID` | قناة سجل التفعيل |
