# 🛡️ Secret CFW - منصة التفعيل

<div dir="rtl">

منصة احترافية لإدارة تفعيل اللاعبين لسيرفر FiveM، تعتمد على موقع ويب متكامل وبوت Discord وقاعدة بيانات PostgreSQL ونظام صلاحيات مرتبط برتب Discord.

## ✨ المميزات الرئيسية

### 🌐 الموقع
- **تصميم عصري متحرك** بهوية أزرق-رصاصي احترافية
- **دعم كامل للغة العربية** مع RTL
- **متوافق مع جميع الأجهزة** (موبايل، تابلت، كمبيوتر)
- **تأثيرات بصرية متقدمة** (جسيمات، توهج، انتقالات سينمائية)
- **وضع تقليل الحركة** لذوي الحساسية للحركة

### 🔐 نظام التفعيل
- نموذج تفعيل متعدد الخطوات
- اختبار كتابي بأسئلة عشوائية
- نظام حالات متعدد (قيد المراجعة، مفعل، مرفوض، طلب تعديل)
- نظام أولوية للرتب المميزة
- إمكانية إعادة التقديم بعد الرفض

### 👑 لوحة التحكم الإدارية
- إحصائيات شاملة ومباشرة
- إدارة الطلبات مع فلترة وبحث
- بنك أسئلة قابل للتعديل
- ملاحظات داخلية وعامة
- سجل نشاط إداري كامل
- نظام ردود سريعة
- وضع صيانة

### 🤖 بوت Discord
- مزامنة تلقائية مع الموقع
- إعطاء/سحب الرتب تلقائياً
- إشعارات للأعضاء والإدارة
- داشبورد تفاعلي في Discord
- أوامر Slash للاستعلام

### 🔒 الأمان
- منع التقديم المتكرر الضار
- كشف الحسابات الجديدة
- منع الإداري من مراجعة طلبه
- تسجيل جميع العمليات

## 🚀 التثبيت

### المتطلبات
- Node.js 18+
- PostgreSQL
- حساب Discord Developer

### الخطوات

1. **استنساخ المشروع**
```bash
git clone https://github.com/your-repo/secret-cfw.git
cd secret-cfw
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **إعداد المتغيرات البيئية**
```bash
cp .env.example .env
# قم بتعديل القيم في ملف .env
```

4. **إعداد قاعدة البيانات**
```bash
npm run db:push
npm run db:seed
```

5. **تشغيل المشروع**
```bash
# للتطوير
npm run dev

# للإنتاج
npm run build
npm start
```

## ⚙️ إعداد Discord

### إنشاء تطبيق Discord
1. اذهب إلى [Discord Developer Portal](https://discord.com/developers/applications)
2. أنشئ تطبيق جديد
3. من قسم OAuth2، أضف Redirect URL: `http://localhost:3000/api/auth/callback/discord`
4. من قسم Bot، أنشئ بوت وانسخ التوكن
5. فعّل الـ Intents المطلوبة:
   - Server Members Intent
   - Message Content Intent

### الرتب المطلوبة
أنشئ الرتب التالية في السيرفر وأضف معرفاتها في `.env`:
- رتبة الإدارة العليا
- رتبة إدارة التفعيل
- رتبة الإدارة العامة
- رتبة المفعل
- رتبة الأولوية (اختياري)

### القنوات المطلوبة
- قناة إشعارات الإدارة
- قناة داشبورد التفعيل
- قناة اللوقات

## 🎨 التخصيص

### تغيير الألوان
عدّل المتغيرات في `src/app/globals.css`:
```css
:root {
  --color-primary: #3b82f6;
  --color-primary-dark: #2563eb;
  /* ... */
}
```

### إضافة أسئلة
استخدم لوحة التحكم الإدارية أو عدّل `prisma/seed.ts`
