# Secret CFW - منصة التفعيل

منصة احترافية لإدارة تفعيل اللاعبين لسيرفر FiveM مع بوت Discord متكامل.

## ✨ المميزات

### 🌐 الموقع
- تسجيل دخول عبر Discord OAuth
- نظام تفعيل متكامل مع اختبار كتابي
- لوحة تحكم للعضو لمتابعة حالة التفعيل
- لوحة تحكم إدارية كاملة
- تصميم متجاوب مع الجوال والكمبيوتر
- دعم RTL كامل للغة العربية
- تصميم متحرك بهوية أزرق-رصاصي

### 🤖 بوت Discord
- مزامنة حالة التفعيل مع الموقع
- إعطاء وسحب الرتب تلقائياً
- إشعارات للإدارة والأعضاء
- أوامر للاستعلام عن الحالة
- داشبورد تفاعلي في قناة مخصصة

### 🛡️ الأمان
- حماية من التقديم المتكرر
- كشف الحسابات الجديدة
- منع الإداري من مراجعة طلبه
- تسجيل جميع العمليات الإدارية

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- PostgreSQL
- تطبيق Discord (للحصول على Client ID و Secret)
- بوت Discord (للحصول على Token)

### التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd secret-cfw
```

2. **تثبيت الحزم**
```bash
npm install
```

3. **إعداد المتغيرات البيئية**
```bash
cp .env.example .env
# قم بتعديل ملف .env بالقيم الخاصة بك
```

4. **إعداد قاعدة البيانات**
```bash
npm run db:push
npm run db:generate
```

5. **تشغيل المشروع**
```bash
# تشغيل الموقع والبوت معاً
npm run dev:all

# أو تشغيل كل واحد على حدة
npm run dev    # الموقع فقط
npm run bot    # البوت فقط
```

## 🔧 المتغيرات البيئية

راجع ملف `.env.example` للحصول على قائمة كاملة بالمتغيرات المطلوبة.

### المتغيرات الأساسية:
- `DATABASE_URL` - رابط اتصال PostgreSQL
- `NEXTAUTH_URL` - رابط الموقع
- `NEXTAUTH_SECRET` - مفتاح سري لـ NextAuth
- `DISCORD_CLIENT_ID` - معرف تطبيق Discord
- `DISCORD_CLIENT_SECRET` - سر تطبيق Discord
- `DISCORD_BOT_TOKEN` - توكن البوت
- `DISCORD_GUILD_ID` - معرف السيرفر
